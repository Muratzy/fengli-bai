# 风力摆 Q1 网页上位机

在 `WindPendulum_F407` 目录启动本地静态文件服务：

```powershell
python -B -m http.server 8765 --bind 127.0.0.1 --directory 上位机
```

在桌面版 Chrome 或 Edge 打开 [Q1 实验台](http://127.0.0.1:8765/)，点击「连接串口」，选择 J-Link 的 **VCOM（Virtual COM Port）**。项目之前的端口是 COM9，实际名称以系统串口选择器为准。串口设定为 115200、8-N-1、无流控。

| STM32 USART1 | J-Link VCOM |
|---|---|
| PA9 TX | RXD |
| PA10 RX | TXD |
| GND | GND |

左侧导航可在总览和四个区域之间切换。未连接 J-Link 时仍可编辑参数和查看本机历史。网页收到兼容固件应答及新鲜遥测后，才根据板端状态启用实验操作。

PA9/PA10 是固件使用的 USART1 信号。原理图上标为「串口1」的 PC6/PC7 是 USART6。已有固件可继续在网页只读监测。启停和调参需要先烧录本项目带 WP1 命令接收功能的固件一次，并接通 PA10。关闭占用同一 COM 口的采集脚本再连接网页。

## 连续调参

1. 输入起摆 PD 的 Kp/Kd、幅值 PID 的 Kp/Ki/Kd、阻尼补偿和目标投影总跨度（cm）。网页按支点高度显示换算后的峰值角度，并以该角度下发。起摆 Ki 固定为 0。目标角度同时用于起摆正弦和后段幅值反馈。
2. 在实验控制区设置运行时长（5–60 秒，默认 25 秒），点击「下发并启动」。STM32 校验参数和时长后锁定本轮配置，到时自动停机，并将实际配置回传。控制和安全保护均在 STM32 上执行。
3. 页面显示运行时间和本轮设定时长，记录从板端带有本轮 ID 的首帧持续到终止帧。点击「停止」后可直接改参数再启动。点击「重置实验」会清除当前实验显示和板端 Q1 运行状态，串口、页面输入与历史记录保留。板上的 KEY3 仍可停机。
4. 实验记录默认展示最新一轮的地面投影轨迹，点编号可查看历史轨迹。基于本轮支点高度及运行态 Roll/Pitch 遥测换算地面位置，上偏为正，下偏为负。右图按运行时间显示有符号的左右投影位移，零线为静止中心。相邻两次从左到右的实测 Pitch 过零界定一个完整周期，摆幅取该周期内左右投影最大值减最小值。下方最多列出最近三个完整周期，未结束的周期和遥测中断的周期不参与统计。CSV 包含全部已接收的本轮遥测字段，JSON 还包含板端确认参数、命令 ID 与结束状态。勾选两轮可按板端运行时间叠加角度、角速度、幅值或有符号 PWM。

在「实验记录」点击「选择数据文件夹」，授权本目录中的 `实验数据`。授权后会补存历史记录，后续每轮结束自动写入 CSV 和 JSON。文件名包含实验编号、启动时间和板端命令 ID。重新打开网页后，若浏览器要求恢复授权，再选同一个文件夹即可。

浏览器按本机地址和端口保留记录。复用同一浏览器配置和地址可在刷新后继续查看。每秒保存一次进行中的记录，结束时另保存终态。已接收遥测为串口快照，采集并不覆盖每一次 MCU 闭环运算。

## 串口协议

请求和应答采用逗号分隔 ASCII，末尾为 `*<四位大写 CRC16>` 和换行。CRC 使用 CCITT-FALSE（初值 `FFFF`，多项式 `1021`）。请求正文为 `!WP1,<非零 uint32 ID>,<命令>[,<参数>...]`。

| 命令 | 行为 |
|---|---|
| `INFO` | 返回当前固件的 Q1 默认值和固定配置 |
| `START` | 携带启动 Kp/Kd、幅值 Kp/Ki/Kd、阻尼补偿、目标角度共七个值，增益、角度均以数值的 1000 倍传输，最后一个可选整数为运行毫秒数。新版网页总是下发设置的时长，省略时固件沿用默认的 25 秒，允许范围为 5–60 秒。 |
| `STOP` | 请求停机 |
| `RESET` | 停机时重置 Q1 的试次状态 |

应答正文为 `!WP1,<ID>,OK,<命令>[,<完整参数快照>...]` 或 `!WP1,<ID>,ERR,<命令>,<原因>`。遥测 CSV 保留既有字段顺序，并附加 `q1_vcom_trial_id`。网页按此 ID 关联遥测和参数应答。居中反馈版本再追加 `q1_center_cdeg` 和 `q1_center_output_milli`，参数快照附上居中反馈配置。旧版 68 列遥测及原有命令应答仍可读取。

幅值阶段将估算幅值送入 PID，PID 输出与阻尼补偿相加后乘以滤波后的 Pitch 角速度，最后经 PWM 限幅。幅值 I、D 默认均为 0，所以默认仍沿用上一轮的比例幅值反馈与阻尼补偿。启用 I 或 D 后的台架表现待实测。

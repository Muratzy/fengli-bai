## 工程构建

后续统一复用 [编译烧录流程](编译烧录流程.md) 与 `Tools/build_flash.ps1`，在本工程目录执行 `pwsh -NoProfile -ExecutionPolicy Bypass -File .\Tools\build_flash.ps1 -Action BuildFlash` 即完成完整编译、下载、校验和运行。

在 CubeIDE 中选择 **File > Import > Existing Projects into Workspace**，导入 `WindPendulum_F407` 文件夹并构建 `Debug` 配置。`.ioc` 保存 CubeMX 引脚和外设配置。Debug/Release 均使用 Cortex-M4、FPv4-SP-D16 和 hard-float ABI；HAL/CMSIS 来源记录在 `Drivers/UPSTREAM_VERSIONS.txt`。

## 硬件接口

| 设备 | 接口配置 |
|---|---|
| OLED | SSD1306，128×64；I2C1 PB6/PB7，100 kHz，7 位地址 `0x3C`（HAL 地址 `0x78`） |
| ICM-45686 | SPI2 PB10/PC2/PC3，PE7 CS；SPI Mode 3，2.625 MHz；传感器量程 ±16 g、±2000 dps，ODR 800 Hz |
| 按键 | KEY1=PC0、KEY2=PC1、KEY3=PC13；台架为固定30%/斜坡20–80%/停止，题目菜单保留确认/上/下，低电平有效 |
| 调试串口 | USART1 PA9/PA10，115200 8-N-1；当前 USB-UART 枚举为 COM9 |
| 扩展串口 | USART2 PD5/PD6，115200 8-N-1 |

完整引脚及预留功能见 `硬件引脚分配.md`。SWD 保留 PA13/PA14，USB 和 TF 卡引脚不分配给本固件。

PB0 / ADC1_IN8 / I1 的电流换算、接线假设和标定见 [ADC电流检测](ADC电流检测.md)。PB1 / ADC1_IN9 / U1 的电压采样换算、VREFINT 补偿、滤波和校准步骤见 [ADC电压检测](ADC电压检测.md)。电机板 H3 的 `Vout` 位于 INA240 电流检测输出链路，H6-U1 是否接到该点需按飞线实物确认；当前读数是中性的 U1 引脚电压占位值，不是经验证的母线电压。

## 菜单和状态

根菜单源码包含 Live Status、IMU Data、Gyro Offsets、Display 和 About；IMU Data 下分 Attitude、Accelerometer、Gyroscope。Display 提供 OLED 对比度调节。状态页显示传感器在线状态、姿态角、加速度和陀螺仪原始值/换算值、温度及固定零偏。当前 `APP_Q2_UI_ENABLED=1`、`APP_OLED_ENABLED=1`，显示专用 Q2 页面，完整菜单未运行。

IMU 任务以 500 Hz 为目标轮询数据。2026-11-23 按用户要求取消上电 5000 点静止校准，经中心和四方向姿态标定后固定使用三轴零偏 `0.31284/-0.08947/0.12095 °/s`，参数在 `app_config.h`。初始化及首次有效采样后直接融合，姿态使用扣除固定零偏后的陀螺仪积分与加速度倾角互补融合，并在快速运动时降低加速度权重。

固定IMU旋转矩阵和陀螺仪零偏来自此前中心及四方向姿态测量。2026-11-23新增激光中心校正：融合加速度角度扣除Roll零偏-0.97740°、Pitch零偏+0.19396°；右侧地面+20 cm点以H=99 cm计算理论Pitch 11.421°，中心修正实测11.600°，差+0.179°，在单点手持校核范围内。源码尚未烧录。旋转矩阵未因单点而重拟合、陀螺仪零偏未改变；上=0°、右=90°、下=180°、左=270°的方向角仍不是绝对航向。单点数据不能说明全方位交叉轴误差，后续多点残差见根目录 [项目交接](../项目交接.md)。

## FreeRTOS 与输出限制

任务链为 `imu -> fusion -> trajectory -> motor -> telemetry`，UI通过队列读取状态。题目模式当前输出58列CSV，PC用 `Tools/q1_trial.py` 采集Q1/Q2，Q2专用数据目录为 `数据记录/串口/Q2/`；旧 `serial_capture.py` 仍仅支持28列台架协议。Q2 CSV另附19列主机时间和换算值，字段及流程见 [电脑串口采集](电脑串口采集.md)。串口只接收，明确start/stop动作通过J-Link RAM命令口控制；默认observe不写命令。所有记录均为快照，不能声称MCU全采样率无丢失。

统一任务 API 为 `PendulumApp_RequestProblemStart(id,&params)`、`PendulumApp_RequestProblemStop()`、`PendulumApp_GetProblemStatus(&status)`。题目注册和参数用法见 [项目逻辑框架](项目逻辑框架.md) 第 2.3 节。Q1/Q2 均使用角度误差和陀螺仪速度误差，输出经过各题 PWM 斜坡和左右互锁。当前增益 32.75/1/8 和 D 滤波 50 ms 为调参候选。停止与故障立即归零，Roll PID 输出和积分均禁用。

2026-11-23 Q1 准备：用户测得万向节中心离地 0.99 m、到风力摆中心 0.67 m，并确认激光与摆杆同轴、沿左右方向往返摆动。地面光点位移满足 `x=0.99×tan(θ)`；50 cm 为两端总长，端点 ±25 cm 对应 Pitch=±14.1723°，Roll 目标为 0。0.67 m 用于简单摆近似周期估算约 1.642 s，不用它换算地面光点位置；实际刚体周期仍需实测。参数集中在 `app_config.h`，`ProblemQ1_DefaultConfig()` 提供左右对称参考轨迹，默认两周期平滑增幅（3.284 s）、15 s 观察窗口；周期与观察窗口分开，窗口到时不代表实测达标。

当前 Q1 使用固定三维安装坐标变换后的 Roll/Pitch 和 `H=0.99 m` 的地面投影参数。`problem_q1.c` 生成 60 cm 总摆幅（端点 ±30 cm、目标角约 ±16.86°）的正弦角度和角速度参考，`q1_swing.c` 计算 Pitch 轴速率 PID。正控制量通过 PWM1 使摆体向右，负控制量通过 PWM2 使摆体向左。新版调试候选在 `app_config.h` 将 Q1 限幅设为 80%，从零升到限幅为 300 ms，从限幅退零为 100 ms。换向时两路 PWM 命令同时为零至少 10 ms。Q1 启动允许 Roll/Pitch 各在 ±7° 内，15 秒结束、KEY3、数据过期、超角和其他故障立即清零，MotorTask 是唯一执行器写入者。旧版 60 cm 实测试次和新版的未烧录状态见 [项目交接](../项目交接.md)。

用户要求每轮得到明确启动指令才运行。下一轮Q2使用 `python -B -X utf8 Tools/q1_trial.py --problem q2 --length-cm 60 --action start --duration 20`，先确认±7°范围、数据有效、PWM/EN关闭，再配置600 mm并发一次启动；先看数据可用相同参数加 `--action observe --duration 2`，停止用 `--action stop --duration 2`。现有58列协议保持原47列顺序并附加11列，PC可兼容旧47列会话。工具保存原始字节、CSV和含分析的session.json；遇到板端重启或启动后超过0.5秒无有效遥测即中止并尝试停止，不自动重试。正常uint32回绕不算重启；没有结束、复位或采集失败的会话不用于调参。最新参数、烧录与实测证据见根目录 [项目交接](../项目交接.md)。

电机1测试为独立的执行器入口，只有测试任务可以输出 CH1，正常题目链路的门控仍保留。PD7 改为开漏并启用内部上拉，以便电机板 LM393/2N7002 下拉 EN 时不会与 MCU 推挽高电平冲突；5 V SN74HC08 对 3.3 V 输入的兼容性仍需实测。

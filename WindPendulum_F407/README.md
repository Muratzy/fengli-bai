## 工程构建

后续统一复用 [编译烧录流程](编译烧录流程.md) 与 `Tools/build_flash.ps1`，在本工程目录执行 `pwsh -NoProfile -ExecutionPolicy Bypass -File .\Tools\build_flash.ps1 -Action BuildFlash` 即完成完整编译、下载、校验和运行。

在 CubeIDE 中选择 **File > Import > Existing Projects into Workspace**，导入 `WindPendulum_F407` 文件夹并构建 `Debug` 配置。`.ioc` 保存 CubeMX 引脚和外设配置。Debug/Release 均使用 Cortex-M4、FPv4-SP-D16 和 hard-float ABI；HAL/CMSIS 来源记录在 `Drivers/UPSTREAM_VERSIONS.txt`。

完整引脚及预留功能见 `硬件引脚分配.md`。SWD 保留 PA13/PA14，USB 和 TF 卡引脚不分配给本固件。

PB0 / ADC1_IN8 / I1 的电流换算、接线假设和标定见 [ADC电流检测](ADC电流检测.md)。PB1 / ADC1_IN9 / U1 的电压采样换算、VREFINT 补偿、滤波和校准步骤见 [ADC电压检测](ADC电压检测.md)。电机板 H3 的 `Vout` 位于 INA240 电流检测输出链路，H6-U1 是否接到该点需按飞线实物确认；当前读数是中性的 U1 引脚电压占位值，不是经验证的母线电压。

## 菜单和状态

根菜单源码包含 Live Status、IMU Data、Gyro Offsets、Display 和 About；IMU Data 下分 Attitude、Accelerometer、Gyroscope。Display 提供 OLED 对比度调节。状态页显示传感器在线状态、姿态角、加速度和陀螺仪原始值/换算值、温度及固定零偏。当前 `APP_OLED_ENABLED=0`，完整菜单未运行。

IMU 任务以 500 Hz 为目标轮询数据。2026-11-23 按用户要求取消上电 5000 点静止校准，经中心和四方向姿态标定后固定使用三轴零偏 `0.31284/-0.08947/0.12095 °/s`，参数在 `app_config.h`。初始化及首次有效采样后直接融合，姿态使用扣除固定零偏后的陀螺仪积分与加速度倾角互补融合，并在快速运动时降低加速度权重。

固定参数来自本机已保存的中心静止和四方向实测，重启和通信重连后沿用。融合前同时旋转加速度和角速度到摆体坐标，中心静止为 0° 倾角，Roll 向上为正、Pitch 向右为正；方向角上=0°、右=90°、下=180°、左=270°，顺时针增大，倾角低于 1° 时方向无效。36 列传感器遥测末尾增加 `direction_cdeg,tilt_cdeg,direction_valid`；这不是绝对航向。手持四方向复算最大偏差约 5°，独立中心平均倾角约 0.12°、右方有效方向均值约 88.2°，详细证据见根目录 [项目交接](../项目交接.md)。当前 `APP_MOTOR1_TEST_ENABLED=0`，运行传感器链路，电机 EN 低、四路 PWM 为零；旧电机台架代码仍保留。

## FreeRTOS 与输出限制

任务链为 `imu -> fusion -> trajectory -> motor -> telemetry`，UI 通过队列读取显示状态。USART1 输出 CSV 遥测，覆盖 IMU、姿态、目标、PID 分项、PWM、原始电流 ADC 和模式。电脑端使用 [电脑串口采集](电脑串口采集.md) 保存每次会话的带主机时间 CSV、原始字节、事件和字段说明；当前采集器只解析电机1测试的 28 列协议，后续 IMU/题目遥测需增加对应适配器。采集器不向 MCU 写入，不改变采样与控制；它仍是串口快照记录，不能宣称 MCU 全采样率无丢失。

2026-11-23 Q1 准备：用户测得万向节中心离地 0.99 m、到风力摆中心 0.67 m，并确认激光与摆杆同轴、沿左右方向往返摆动。地面光点位移满足 `x=0.99×tan(θ)`；50 cm 为两端总长，端点 ±25 cm 对应 Pitch=±14.1723°，Roll 目标为 0。0.67 m 用于简单摆近似周期估算约 1.642 s，不用它换算地面光点位置；实际刚体周期仍需实测。参数集中在 `app_config.h`，`ProblemQ1_DefaultConfig()` 提供左右对称参考轨迹，默认两周期平滑增幅（3.284 s）、15 s 观察窗口；周期与观察窗口分开，窗口到时不代表实测达标。

最新 Q1 试验采用端点换向。用户已澄清摆体反作用运动方向：**左电机 PWM1 开启让摆体向右动，右电机 PWM2 开启让摆体向左动**；角速度接近零且已偏离中心时换向。启动允许Roll/Pitch各在±7°内，不要求静止或低角速度；当前占空比0%～100%，从0升到100%用500 ms。正常换向先用200 ms将旧侧从100%降至零，再让另一侧从零渐升，始终左右互锁。参数为 `APP_Q1_START_ANGLE_DEG`、`APP_Q1_PWM_START_PERMILLE/MAX_PERMILLE/RISE_MS/FALL_MS`。`problems/q1_swing.c` 根据角度和角速度估算摆幅，到目标能量时降零滑行，幅度不足再渐升补力；`problem_q1.c` 正弦参考与 PID 模块暂不参与本轮执行。默认上电待机，电机 EN 低、PWM零，收到一次启动命令才允许 MotorTask 输出左右通道；上/下电机恒零。每次15秒结束、丝印KEY3停止及任何故障立即清零，不等待斜坡；故障锁定后需重新明确启动。已验证的20%～80%/升1000 ms/退400 ms版本已保存为本地恢复包，本次修改不覆盖它。

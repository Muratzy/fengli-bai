# 风力摆 F407 固件

对话接续先看根目录 [项目交接](../项目交接.md) 和 [协作与本地 Git 约定](../AGENTS.md)。按本轮用户提供的 AGENTS.md，每完成一个独立部分并检查后主动本地提交；GitHub 上传由用户另行要求。

项目使用天空星青春版 STM32F407VET6，在 STM32CubeIDE 1.19.0 中构建，FreeRTOS 版本为 202406.04 LTS。Q1 当前采用起摆 PID 与幅值反馈 PID 两阶段混合控制；Q2 是单独选择、单独运行的 Pitch PID 模式，两问不会并行控制电机。Q2 当前 `32.75/0/8` 仅为未调稳的调试起点，摆幅、长度精度和重复性未达标，不能视为第二问验收通过。Q1/Q2 已接入统一启动、停止和查询 API，Q3～Q7 尚未实现。Q2 OLED 页可设置 30～60 cm 总长并启动或停止 Q2。Q1 调试窗口为 25 秒，Q2 窗口为 15 秒。题目验收以实际轨迹和赛题时限为准。

需求以根目录 [风力摆控制系统(B题).pdf](../风力摆控制系统(B题).pdf) 和用户确认的调整为准；训练题文档已删除，其附加验收项不再纳入项目。IMU 使用固定标定零偏，按用户要求取消上电静止校准；完整数据记录作为可选调试功能，电脑端串口采集已经可以按会话保存 CSV、原始字节和事件。

2026-11-16 的电机1台架固件记录仍保留在 [电机1测试](电机1测试.md) 和 [项目交接](../项目交接.md) 中；当前工作区配置为 `APP_MOTOR1_TEST_ENABLED=0`、`APP_Q2_UI_ENABLED=1`，默认进入 Q2 调试/待机路径，未授权时不启动电机。台架历史按键为 KEY1=PC0、KEY2=PC1、KEY3=PC13；PWM 初始化清零后 EN 默认拉高，KEY1 固定 30%，KEY2 从 20% 逐步增加到 80%，KEY3 停止。Q2 题目模式由统一题目 API 和 MotorTask 门控，不能与台架测试并行占用执行器。

项目后续开发统一遵循 [项目逻辑框架](项目逻辑框架.md)：以 OLED 选择比赛题目 Q1–Q7，每问由独立任务块执行，并通过统一的参数检查、任务生命周期、结果记录和安全停止流程。

2026-11-17 电流测量修正：参考本地克隆的 7Semi-INA240，PB0 改为每周期保留 8 笔、先平均再扣零点换算；保留单样本兼容入口与 28 列遥测。新增显式零电流确认的纯算法标定接口，默认不自动执行；参数和限制见 [ADC电流检测](ADC电流检测.md)。源码 `a2fbe6b` 对应固件已按用户后续“烧录”要求下载、校验并复位运行，实物电流标定仍待完成。

## 工程构建

后续统一复用 [编译烧录流程](编译烧录流程.md) 与 `Tools/build_flash.ps1`，在本工程目录执行 `pwsh -NoProfile -ExecutionPolicy Bypass -File .\Tools\build_flash.ps1 -Action BuildFlash` 即完成完整编译、下载、校验和运行。

在 CubeIDE 中选择 **File > Import > Existing Projects into Workspace**，导入 `WindPendulum_F407` 文件夹并构建 `Debug` 配置。`.ioc` 保存 CubeMX 引脚和外设配置。Debug/Release 均使用 Cortex-M4、FPv4-SP-D16 和 hard-float ABI；HAL/CMSIS 来源记录在 `Drivers/UPSTREAM_VERSIONS.txt`。

完整引脚及预留功能见 `硬件引脚分配.md`。SWD 保留 PA13/PA14，USB 和 TF 卡引脚不分配给本固件。

PB0 / ADC1_IN8 / I1 的电流换算、接线假设和标定见 [ADC电流检测](ADC电流检测.md)。PB1 / ADC1_IN9 / U1 的电压采样换算、VREFINT 补偿、滤波和校准步骤见 [ADC电压检测](ADC电压检测.md)。电机板 H3 的 `Vout` 位于 INA240 电流检测输出链路，H6-U1 是否接到该点需按飞线实物确认；当前读数是中性的 U1 引脚电压占位值，不是经验证的母线电压。

## 菜单和状态

根菜单源码包含 Live Status、IMU Data、Gyro Offsets、Display 和 About；IMU Data 下分 Attitude、Accelerometer、Gyroscope。Display 提供 OLED 对比度调节。状态页显示传感器在线状态、姿态角、加速度和陀螺仪原始值/换算值、温度及固定零偏。当前 `APP_Q2_UI_ENABLED=1`、`APP_OLED_ENABLED=1`，显示专用 Q2 页面，完整菜单未运行。

IMU 任务以 500 Hz 为目标轮询数据。2026-11-23 按用户要求取消上电 5000 点静止校准，经中心和四方向姿态标定后固定使用三轴零偏 `0.31284/-0.08947/0.12095 °/s`，参数在 `app_config.h`。初始化及首次有效采样后直接融合，姿态使用扣除固定零偏后的陀螺仪积分与加速度倾角互补融合，并在快速运动时降低加速度权重。

固定IMU旋转矩阵和陀螺仪零偏来自此前中心及四方向姿态测量。2026-11-23新增激光中心校正：融合加速度角度扣除Roll零偏-0.97740°、Pitch零偏+0.19396°；右侧地面+20 cm点以H=99 cm计算理论Pitch 11.421°，中心修正实测11.600°，差+0.179°，在单点手持校核范围内。源码尚未烧录。旋转矩阵未因单点而重拟合、陀螺仪零偏未改变；上=0°、右=90°、下=180°、左=270°的方向角仍不是绝对航向。单点数据不能说明全方位交叉轴误差，后续多点残差见根目录 [项目交接](../项目交接.md)。

## FreeRTOS 与输出限制

任务链为 `imu -> fusion -> trajectory -> motor -> telemetry`，UI 通过队列读取状态。[Q1 网页上位机](上位机/README.md) 支持通过 J-Link VCOM 连续调参、启停、看实时曲线和保存试次。Q1/Q2 使用 `Tools/q1_trial.py` 采集，板端新版输出 70 列 CSV，包含 PWM 上限、网页试次 ID、中心估计和居中修正。每次试验自动保存控制曲线与分析指标。Q2 专用数据目录为 `数据记录/串口/Q2/`。Python 工具的串口路径只接收遥测，启停走 J-Link RAM 命令。字段及流程见 [电脑串口采集](电脑串口采集.md)。

统一任务 API 为 `PendulumApp_RequestProblemStart(id,&params)`、`PendulumApp_RequestProblemStop()`、`PendulumApp_GetProblemStatus(&status)`。题目注册和参数用法见 [项目逻辑框架](项目逻辑框架.md) 第 2.3 节。Q1 两阶段实验先用 28/0/7 实测角速度阻尼 PD 起摆，幅值估计达到目标的 90% 并保持 250 ms 后，以 1642 ms 平滑混合进入幅值反馈，首轮 `Ka=2.0`、`K_comp=0.5`；Q2 的 D 项取目标与实测角速度之差的低通滤波值乘以 `Kd`。Q1 实验窗口为 25 s，Q2 增益为 32.75/0/8。两问 D 滤波时间常数为 50 ms。控制随新的有效融合数据更新，名义间隔 2 ms。停止与故障立即归零，Roll 轴闭环禁用。

万向节中心离地 0.99 m，到风力摆中心 0.67 m。激光与摆杆同轴，沿左右方向往返摆动。当地面轨迹沿 Pitch 轴时，光点位移满足 `x=0.99×tan(θ)`，端点 ±25 cm 对应 Pitch=±14.1723°，Roll 目标为 0。Q1 当前基准参考周期为 1.642 s，`ProblemQ1_DefaultConfig()` 用两个参考周期（3.284 s）平滑增幅。Q2 单独使用自由衰减实测周期 1.610 s。

当前 Q1 使用固定三维安装坐标变换后的 Roll/Pitch 和 `H=0.99 m` 的地面投影参数。`problem_q1.c` 生成 60 cm 总摆幅（端点 ±30 cm、目标角约 ±16.86°）的正弦角度和角速度参考，`q1_swing.c` 计算 Pitch 轴速率 PID。正控制量通过 PWM1 使摆体向右，负控制量通过 PWM2 使摆体向左。Q1 每帧直接传递限幅后的 PWM，源码上限为 85%。MotorTask 在通道切换时关闭 EN、锁存 CCR 后再使能，是唯一执行器写入者。Q1 启动允许 Roll/Pitch 各在 ±7° 内，25 秒到时、KEY3、数据过期、超角和其他故障立即清零。最近一次实测见 [项目交接](../项目交接.md)。

当前 Q2 台架默认总长度为 50 cm，PWM 上限为 85%。参考周期按 Pitch 自由衰减测量设为 1610 ms，参考增幅用两个周期（3220 ms）。限幅后每个控制周期直接更新左右 PWM。MotorTask 校验左右互斥，在输出通道切换时于同一次任务调用内短暂关 EN、更新 CCR、再开 EN。

使用 `python -B -X utf8 Tools/q1_trial.py --problem q2 --length-cm 50 --action observe --duration 2` 核对待机。获准启动后改用 `--action start --duration 20`，脚本核对姿态在 ±7° 内、数据有效、PWM 与 EN 为零后配置 500 mm 并启动一次。停止用 `--action stop --duration 2` 或 KEY3。

题目采集器兼容 47、58、59、67、68 和 70 列会话。遇到板端重启或启动后超过 0.5 秒无有效遥测时，采集器中止并尝试停止。最新参数、烧录与实测证据见根目录 [项目交接](../项目交接.md)。

电机1测试为独立的执行器入口，只有测试任务可以输出 CH1，正常题目链路的门控仍保留。PD7 改为开漏并启用内部上拉，以便电机板 LM393/2N7002 下拉 EN 时不会与 MCU 推挽高电平冲突；5 V SN74HC08 对 3.3 V 输入的兼容性仍需实测。

项目使用天空星青春版 STM32F407VET6，在 STM32CubeIDE 1.19.0 中构建，FreeRTOS 版本为 202406.04 LTS。Q1/Q2 共用两阶段摆动控制器和统一启动、停止、查询 API。上位机 Q1/Q2 共用入口使用 Q1 参数和运行窗口，独立网页 Q2 入口标记为弃用；板端 OLED 的 Q2 入口仍保留。用户于 2026-11-26 确认第二问通过。Q3 指定方向直线已接入 BLE WP1 下发和实验记录，Q4 制动已接入软件并待台架验收。Q5～Q7 尚未实现。

需求以根目录 [风力摆控制系统(B题).pdf](../风力摆控制系统(B题).pdf) 和用户确认的调整为准；训练题文档已删除，其附加验收项不再纳入项目。IMU 使用固定标定零偏，按用户要求取消上电静止校准；完整数据记录作为可选调试功能，电脑端串口采集已经可以按会话保存 CSV、原始字节和事件。

2026-11-16 的电机1台架固件记录仍保留在 [电机1测试](电机1测试.md) 和 [项目交接](../项目交接.md) 中；当前工作区配置为 `APP_MOTOR1_TEST_ENABLED=0`、`APP_Q2_UI_ENABLED=1`，默认进入 Q2 调试/待机路径，未授权时不启动电机。台架历史按键为 KEY1=PC0、KEY2=PC1、KEY3=PC13；PWM 初始化清零后 EN 默认拉高，KEY1 固定 30%，KEY2 从 20% 逐步增加到 80%，KEY3 停止。Q2 题目模式由统一题目 API 和 MotorTask 门控，不能与台架测试并行占用执行器。

项目后续开发统一遵循 [项目逻辑框架](项目逻辑框架.md)：以 OLED 选择比赛题目 Q1–Q7，每问由独立任务块执行，并通过统一的参数检查、任务生命周期、结果记录和安全停止流程。

## 工程构建

后续统一复用 [编译烧录流程](编译烧录流程.md) 与 `Tools/build_flash.ps1`，在本工程目录执行 `pwsh -NoProfile -ExecutionPolicy Bypass -File .\Tools\build_flash.ps1 -Action BuildFlash` 即完成完整编译、下载、校验和运行。

在 CubeIDE 中选择 **File > Import > Existing Projects into Workspace**，导入 `WindPendulum_F407` 文件夹并构建 `Debug` 配置。`.ioc` 保存 CubeMX 引脚和外设配置。Debug/Release 均使用 Cortex-M4、FPv4-SP-D16 和 hard-float ABI；HAL/CMSIS 来源记录在 `Drivers/UPSTREAM_VERSIONS.txt`。

## 菜单和状态

根菜单源码包含 Live Status、IMU Data、Gyro Offsets、Display 和 About；IMU Data 下分 Attitude、Accelerometer、Gyroscope。Display 提供 OLED 对比度调节。状态页显示传感器在线状态、姿态角、加速度和陀螺仪原始值/换算值、温度及固定零偏。当前 `APP_Q2_UI_ENABLED=1`、`APP_OLED_ENABLED=1`，默认显示 Q2 页面，待机时按 KEY2+KEY3 循环 Q2/Q3/Q4。

IMU 任务以 500 Hz 为目标轮询数据。2026-11-23 按用户要求取消上电 5000 点静止校准，经中心和四方向姿态标定后固定使用三轴零偏 `0.31284/-0.08947/0.12095 °/s`，参数在 `app_config.h`。初始化及首次有效采样后直接融合，姿态使用扣除固定零偏后的陀螺仪积分与加速度倾角互补融合，并在快速运动时降低加速度权重。

固定IMU旋转矩阵和陀螺仪零偏来自此前中心及四方向姿态测量。2026-11-23新增激光中心校正：融合加速度角度扣除Roll零偏-0.97740°、Pitch零偏+0.19396°；右侧地面+20 cm点以H=99 cm计算理论Pitch 11.421°，中心修正实测11.600°，差+0.179°，在单点手持校核范围内。源码尚未烧录。旋转矩阵未因单点而重拟合、陀螺仪零偏未改变；上=0°、右=90°、下=180°、左=270°的方向角仍不是绝对航向。单点数据不能说明全方位交叉轴误差，后续多点残差见根目录 [项目交接](../项目交接.md)。

## FreeRTOS 与输出限制

任务链为 `imu -> fusion -> trajectory -> motor -> telemetry`，UI 通过队列读取状态。[Q1 网页上位机](上位机/README.md) 支持通过 J-Link VCOM 或 HC-05 BLE GATT 连续调参、启停、看实时曲线和保存试次。两种网页链路共享 WP1 协议。Q1/Q2 使用 `Tools/q1_trial.py` 采集，板端新版输出 70 列 CSV，包含 PWM 上限、网页试次 ID、中心估计和居中修正。每次试验自动保存控制曲线与分析指标。Q2 专用数据目录为 `数据记录/串口/Q2/`。Python 工具的串口路径只接收遥测，启停走 J-Link RAM 命令。字段及流程见 [电脑串口采集](电脑串口采集.md)。

统一任务 API 为 `PendulumApp_RequestProblemStart(id,&params)`、`PendulumApp_RequestProblemStop()`、`PendulumApp_GetProblemStatus(&status)`。Q1/Q2 的 Pitch 控制默认使用 28/0/7 的实测角速度阻尼 PD 起摆，D 滤波时间常数为 50 ms。幅值估计达到目标的 90% 并保持 250 ms 后，以 1642 ms 平滑混合进入幅值反馈和居中修正，默认幅值 PID 为 2/0/0、阻尼补偿为 0.5。控制随新的有效融合数据更新，名义间隔 2 ms。停止与故障立即归零。 [项目逻辑框架](项目逻辑框架.md)

万向节中心离地 0.99 m，到风力摆中心 0.67 m。激光与摆杆同轴，沿左右方向往返摆动。当地面轨迹沿 Pitch 轴时，光点位移满足 `x=0.99×tan(θ)`，端点 ±25 cm 对应 Pitch=±14.1723°，Roll 目标为 0。两问的参考周期均为 1.642 s，`ProblemQ1_DefaultConfig()` 用两个参考周期（3.284 s）平滑增幅。

当前 Q1 使用固定三维安装坐标变换后的 Roll/Pitch 和 `H=0.99 m` 的地面投影参数。`problem_q1.c` 生成 60 cm 总摆幅（端点 ±30 cm、目标角约 ±16.86°）的正弦角度和角速度参考，`q1_swing.c` 计算 Pitch 轴速率 PID。正控制量通过 PWM1 使摆体向右，负控制量通过 PWM2 使摆体向左。Q1 每帧直接传递限幅后的 PWM，源码上限为 85%。MotorTask 在通道切换时关闭 EN、锁存 CCR 后再使能，是唯一执行器写入者。Q1 启动允许 Roll/Pitch 各在 ±7° 内，本轮运行时长到期、KEY3、数据过期、超角和其他故障均立即清零。最近一次实测见 [项目交接](../项目交接.md)。

Q2 默认目标总长为 50 cm，运行 15 秒。Q2 OLED 启动使用固件默认控制参数。上位机不提供独立 Q2 启动入口，Q1/Q2 共用入口用于同一两阶段控制器调试。

### Q3 指定方向直线

Q3 默认总长 25 cm、窗口 15 秒。方向角按上 0°、右 90°、下 180°、左 270°定义，顺时针递增。OLED 待机时按 KEY2+KEY3 切换到 Q3，KEY2/KEY3 按 10°增减方向，KEY1 请求启动，运行时 KEY3 停止。统一 API 支持总长 200～600 mm，OLED 当前使用 250 mm 默认值。

`q3_direction.c` 将地面投影分解为沿线和垂线方向。沿线复用起摆 PD、幅值 PID、居中修正，垂线使用 PD 回正，再合成为 Roll/Pitch 输出。候选增益沿用启动 28/0/7、幅值 2/0/0、补偿 0.5，参考周期暂用 1642 ms。各对反向电机互斥，四路占空比之和最多 850‰，到时或保护停机归零。该总量预算由本轮选定，实际电流与推力需要实测。

按用户确认的推力关系，Q3 使用 `APP_Q3_ROLL_SIGN=-1`。上侧 PWM3 向下推摆体，下侧 PWM4 向上推摆体。Q3 经 BLE GATT 查询固件能力并下发方向、总长和控制增益，实验记录按设定方向计算坐标投影。固件配置为 0 时，板端和网页会锁定 Q3 启动。先验证纯上下方向，再验证斜向。地面轨迹的长度、方向、完成时间和重复性需尺量或录像验收。

Q3 遥测题号为 3、运行 mode=10，沿用 70 列。`q1_amplitude_*` 和 `q1_center_*` 表示沿线控制量，Roll/Pitch 和四路 PWM 使用实际轴值。Q3 启动入口包括 OLED、统一题目 API 和网页 BLE。网页试次按题号和命令 ID 匹配，并保存板端确认的方向及长度。

### Q4 制动

Q4 可从网页使用 BLE 或 J-Link VCOM 的 WP1 `Q4INFO`、`Q4ARM`，也可在 OLED 待机时按 KEY2+KEY3 循环到 Q4 后按 KEY1 预备。预备时电机关闭。把摆体拉至 30°～45°并静止保持 150 ms 以上，再朝中心释放。检测到向中心角速度达到 8°/s 后，板端以当前零角度为目标执行双轴 PD 制动，并从释放检测时刻开始计 5 秒。倾角不超过 2°且合成角速度不超过 5°/s 连续 300 ms 判定停稳。超过 20 秒未检测到释放、5 秒内未停稳、倾角超过 50°、合成角速度超过 240°/s、IMU 样本过期或 KEY3 均会停机。

Q4 的初始双轴候选增益为 Kp=10、Kd=8、Ki=0，总 PWM 软件上限 85%。这些增益和物理停稳表现仍待台架验收。Q4 使用独立 `Q4INFO`/`Q4ARM` 能力查询与预备命令，不使用 Q1 的周期参数。题号为 4、运行 mode=5，`q1_run_ms` 表示检测释放后的时间，`q1_control_phase` 的 0/1/2 表示等待释放、制动、停稳观察。结束原因 9/10/11 表示已停稳、释放超时、制动超时。网页保存角度、双轴角速度、四路 PWM 和结果快照。BLE 遥测约 1 Hz，曲线点数受链路周期限制。

### Q1/Q2 电脑端采集

使用 `python -B -X utf8 Tools/q1_trial.py --problem q2 --length-cm 50 --action observe --duration 2` 核对待机。获准启动后改用 `--action start --duration 20`，脚本核对姿态在 ±7° 内、数据有效、PWM 与 EN 为零后配置 500 mm 并启动一次。停止用 `--action stop --duration 2` 或 KEY3。

题目采集器兼容 47、58、59、67、68 和 70 列会话。遇到板端重启或启动后超过 0.5 秒无有效遥测时，采集器中止并尝试停止。最新参数、烧录与实测证据见根目录 [项目交接](../项目交接.md)。

电机1测试为独立的执行器入口，只有测试任务可以输出 CH1，正常题目链路的门控仍保留。PD7 改为开漏并启用内部上拉，以便电机板 LM393/2N7002 下拉 EN 时不会与 MCU 推挽高电平冲突；5 V SN74HC08 对 3.3 V 输入的兼容性仍需实测。

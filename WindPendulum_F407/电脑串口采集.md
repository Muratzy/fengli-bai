# 电脑端串口数据采集

当前 MCU 通过 USART1 的 PA9 TX 输出电机测试遥测。电脑端使用 J-Link 的虚拟串口 COM9 接收，配置为 115200、8 数据位、无校验、1 停止位、无流控。接线为：主控 PA9 TX → J-Link RX，主控与 J-Link 共地。PA10 到 J-Link TX 只在以后需要电脑向板子发送命令时使用；本采集器不会向串口写入任何字节，也没有复位控制线。打开端口前请求 DTR/RTS 为低，但 Windows 驱动打开端口时可能短暂改变控制线。

## 启动

在 `WindPendulum_F407` 目录执行：

```powershell
python -m pip install -r .\Tools\requirements-pc.txt
python .\Tools\serial_capture.py --port COM9
```

需要确认端口时执行：

```powershell
python .\Tools\serial_capture.py --list-ports
```

采集会一直运行，按 `Ctrl+C` 结束。短时间验证可以使用：

```powershell
python .\Tools\serial_capture.py --port COM9 --duration 10 --label bench
```

也可以使用 PowerShell 封装：

```powershell
.\Tools\capture_serial.ps1 -Port COM9 -Duration 10 -Label bench
```

默认输出到 `WindPendulum_F407/数据记录/串口/`，每次启动创建一个独立目录，例如 `20261116_221500_COM9_bench`。采集器可以从任意一行接入，不要求重新下载固件；如果串口暂时断开，会记录断开事件并按固定间隔重连。`-Duration 0` 表示持续采集，负数会被拒绝。

## 文件

| 文件 | 作用 |
|---|---|
| `telemetry.csv` | 可直接用 Excel 或 Python 读取的结构化记录。前 8 列是电脑端上下文，随后严格保留固件 28 列原顺序，最后附加百分比、安培、伏特和按键位解码值 |
| `raw.bin` | 串口实际收到的全部字节，包含启动横幅、协议头、坏行和停止时未完成的行 |
| `events.csv` | 连接、协议头、坏行、超长行、断开、时间回绕/复位等事件及主机时间 |
| `fields.csv` | 每列顺序、单位和含义；`pc_sequence` 是主机行号，不是 MCU 序号 |
| `session.json` | 端口配置、开始/结束时间、采集统计、协议校验状态和本地最近一次构建/烧录清单（若存在） |

采集器只把通过字段数、枚举、布尔值和范围校验的行写入 `telemetry.csv`。协议头尚未出现时，会按工程内置的 28 列协议暂时解析，并在会话元数据中标注；收到匹配协议头后会解除该标记。收到不同版本的 `time_ms,...` 协议头后会停止结构化解析，只继续保存原始字节和异常事件，避免列错位；即使之后又收到匹配头，本次会话仍以退出码 4 标记协议曾不匹配。

`board_epoch` 和 `board_event` 用于区分正常递增、uint32 时间回绕和疑似复位。它们是主机根据收到的数据推断的；断线期间的复位无法可靠观察，某些回绕和复位情形也可能相似。`connection_id` 用来区分串口重连。`timing_gap_suspected=1` 只表示相邻板端时间超过默认 250 ms，不能精确证明丢失了多少帧，因为固件协议没有序号或校验和。

## 当前 28 列协议

协议头来自 `Core/Src/diagnostics/motor1_test_stm32.c`，字段的完整单位和说明以每次会话中的 `fields.csv` 为准。`current_ma`、`current_filtered_ma` 和导出的 `current_a` 仍必须结合 `current_calc_valid`、`current_overrange`、`reference_calibrated` 判断，尚未通过实物标定时不能当作精确电流。PB1 的 U1 数值也保留 `voltage_valid`，不能仅凭 CSV 列名认定为已标定母线电压。

## 验证与限制

采集器的解析测试位于 `tests/test_serial_capture.py` 和 `tests/test_serial_receiver_io.py`，共 16 项，覆盖合法行、半行、坏行、协议头变化、时间回绕、复位、断线重连和保存失败。它没有修改 MCU 工程；实际串口接收是否有数据仍取决于 PA9 到 J-Link RX、共地、板子供电和 COM9 枚举状态。J-Link 能下载 SWD 不等于 USART1 已经接通。实测会话 `数据记录/串口/20261116_223541_COM9_pc_receiver_fixed` 收到 100 行、0 条坏行、9571 字节，板端间隔为 100 ms；停止瞬间保留了 1 字节未成行数据在 `raw.bin` 中。

当前文档和采集器只支持电机1测试的 28 列协议。尚未把 IMU、姿态融合或 Q1–Q7 题目遥测接入该解析器；后续协议确定后应增加独立字段版本或适配器，不能直接套用本协议的列含义。

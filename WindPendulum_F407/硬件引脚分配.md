# 风力摆硬件引脚分配

目标板为天空星青春版，主控 STM32F407VET6（LQFP100）。本表以当前板卡引脚表为准；CubeMX 配置保存在 `WindPendulum_F407.ioc`。

| 功能 | MCU 引脚 | 工程配置 |
|---|---|---|
| OLED I2C1 | PB6 SCL, PB7 SDA | SSD1306 128×64；100 kHz；7 位地址 0x3C（HAL 地址 0x78）；开漏，外部上拉 |
| 蜂鸣器 | PD12 | GPIO 输出，启动低电平 |
| 按键 | PC0, PC1, PC13 | GPIO 输入，上拉 |
| ICM-45686 SPI2 | PB10 SCK, PC2 MISO, PC3 MOSI | SPI 主机，Mode 3；PCLK1 42 MHz / 16 = 2.625 MHz |
| ICM-45686 控制 | PE7 CS, PD0 INT1, PD1 INT2 预留 | CS 高电平不选中；INT1/INT2 配置下降沿输入 |
| 风机 PWM | PE9/PE11/PE13/PE14, TIM1_CH1..CH4 | 20 kHz，比较值启动为 0 |
| 风机控制 | PD7 使能, PD10 故障 | 使能启动低电平；故障脚上拉输入 |
| 激光 | PD8 | GPIO 输出，启动低电平 |
| ADC1 | PB0 电流, PB1 母线电压, PC4 传感器电压, PC5 备用 | ADC1_IN8/9/14/15；当前代码只读取 PB0 原始计数 |
| 调试串口 | PA9 TX, PA10 RX, USART1 | 115200 8-N-1 |
| 扩展串口 | PD5 TX, PD6 RX, USART2 | 115200 8-N-1 |
| 辅助预留 | PE8, PE10, PE12, PD11 | 保持未分配 |
| TIM1 硬件保护预留 | PE15 TIM1_BKIN | 引出复用脚；尚未使能刹车功能，待确认外部极性和电路 |
| 其他预留 | PD13, PD14, PD15, PA4, PA5 | 保持未分配 |
| SWD | PA13 SWDIO, PA14 SWCLK | 保留调试下载 |
| USB | PA11, PA12 | 不分配给 GPIO/其他外设 |
| TF 卡 | PC8-PC12, PD2, PD3 | 不分配给 GPIO/其他外设 |

外部高速晶振按原理图配置为 8 MHz；系统时钟为 168 MHz，APB1 为 42 MHz、APB2 为 84 MHz。TIM1 时钟为 168 MHz，因此 ARR=8399、PSC=0 对应 20 kHz PWM。

ICM-45686 传感器 ODR 配置为 800 Hz，FreeRTOS 采集任务以 500 Hz 轮询；上电静止校准需要连续 5000 个有效样本，约 10 秒。当前使用轮询读取，INT1/INT2 暂未接入采样任务。

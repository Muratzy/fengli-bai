# 主控硬件引脚分配（原理图基准）

本表以主控板和电机板原理图为准，作为硬件连接的记录。两板的连接方式和逐针飞线表见 [原理图核对与飞线表](../硬件配置/风力摆主控与电机板/原理图核对与飞线表.md)。原理图与当前 CubeIDE 工程配置存在差异；在同步前，不要把工程中的外设标签视为实际板级连接。

目标主控：天空星青春版，STM32F407VET6。

## 主控板信号

| 功能 | 原理图信号 / MCU 引脚 | 备注 |
|---|---|---|
| OLED | I2C1：PB6 SCL、PB7 SDA | SSD1306，128×64，7 位地址 0x3C（HAL 地址 0x78，参数由用户确认） |
| 按键 | KEY1：PC13、KEY2：PC0、KEY3：PC1 | 2026-11-16 按用户确认的操作编号；按下接地，低电平有效 |
| 蜂鸣器 | PD12 / Buzzer_T1 | 经 4.7 kΩ 和 SS8050 驱动，MCU 高电平开启 |
| IMU SPI | SPI2：PB10 SCK、PC2 MISO、PC3 MOSI | 主控 H5 与电机板 H8 按信号名飞线 |
| IMU 控制 | PE7 CS、PD0 INT1、PD1 INT2 | 原理图中 INT1、INT2 都已连接，不把 INT2 仅作为未接预留 |
| TIM1_CH1 / 电机通道1 | PE9（主控图纸网名 PWM4） | 主控接口 5 脚交叉焊到电机板 H2 1 脚 PWM1 |
| TIM1_CH2 / 电机通道2 | PE11（主控图纸网名 PWM3） | 主控接口 4 脚交叉焊到电机板 H2 2 脚 PWM2 |
| TIM1_CH3 / 电机通道3 | PE13（主控图纸网名 PWM2） | 主控接口 3 脚焊到电机板 H2 3 脚 PWM3 |
| TIM1_CH4 / 电机通道4 | PE14（主控图纸网名 PWM1） | 主控接口 2 脚交叉焊到电机板 H2 4 脚 PWM4 |
| 电机使能 | PD7 / EN | 主控接口 1 脚，接电机板 H2 5 脚；开漏上拉。电机测试模式 PWM 初始化后默认写高，普通停止清零 PWM；硬故障拉低，板上保护仍可下拉 |
| 激光接口 | PD8 | 主控 H4 2 脚为信号，1 脚为 GND |
| ADC 模拟量 | PB0=I1/ADC1_IN8；PB1=U1/ADC1_IN9；PC4=U2/ADC1_IN14；PA2=I2/ADC1_IN2 | 主控 H6：1=I2、2=U2、3=U1、4=I1 |
| 未明确模拟量 | PC5 / C5 | 主控图上有 C5 网名，但没有标明传感器或外部用途；先按未分配处理 |
| 串口1接口 | PC6=TX1、PC7=RX1 | 在 STM32F407 上对应 USART6_TX/RX，不是 USART1；接口本身标为“串口1” |
| 扩展串口2 | PD5=TX2、PD6=RX2 | 对应 USART2；板上接口为 4 针串口口 |
| 蜂鸣器、按键以外的保留 IO | PE8、PE10、PE12、PD11、PD13、PD14、PD15、PA4、PA5 | 保持预留；具体板上引出关系见主控原理图 |
| TIM1_BKIN | PE15 | 可作为 MCU 复用脚预留；图纸未显示它接到电机板保护输入 |
| PD10 | 暂不部署 | 图纸未显示其与电机板故障输出相连；保持未接线、未使用 |

## 工程记录

以下是已有 CubeIDE 工程记录，不代表已按本次原理图完成同步或实板验证：

- 当前 `.ioc` 将 PA9/PA10 配为 USART1 调试串口；原理图的“串口1”接口实际接 PC6/PC7（USART6）。
- 当前 `.ioc` 的 PE9/PE11/PE13/PE14 分别对应 TIM1_CH1/CH2/CH3/CH4。主控图纸的 PWM 网名顺序相反，焊接时按上表反向交叉，使电机板 H2 的 PWM1..PWM4 分别由 TIM1_CH1..CH4 驱动；因此软件控制数组仍按电机板逻辑 PWM1..PWM4 排列，不按主控焊盘上的网名排列。
- PD10 暂不部署：原理图未显示其与电机板故障输出相连，当前 `.ioc`、GPIO 初始化和引脚宏均不配置或使用 PD10。
- 2026-11-16：用户确认 PE9 接电机板 PWM1、PD7 接 EN、实际供电 5 V，已装桨；进入 [电机1测试](电机1测试.md)。图示 SN74HC08 使用 +5 V，3.3 V 控制电平是否可靠仍待实测。
- 当前 `.ioc` 的 ADC1 常规转换配置只列出 ADC_CHANNEL_8；其余原理图模拟量尚未据此确认已配置。
- 工程原有时钟、PWM 频率、SPI 模式、IMU ODR 和采样任务参数继续以源码及 `.ioc` 为准，不属于原理图确认结果。

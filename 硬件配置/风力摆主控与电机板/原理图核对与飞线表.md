# 风力摆主控板与电机板原理图核对记录

核对日期：2026-11-09

## 板间关系

主控板架在上层，电机板位于下层。主控板承载 STM32F407VET6（天空星青春版）、OLED、按键等；电机板承载电机驱动及 ICM-45686 模块。主控板通过飞线向下连接电机板的 IMU SPI/中断信号和四路 PWM/使能信号。本文按两份原理图和用户说明记录预期连接关系，不代表飞线已经安装或实测。

依据文件：

- `主控SCH_Schematic1_2026-11-09.pdf`
- `电机SCH_Schematic1_2026-11-09.pdf`

IMU 两端按信号名对应，不能把两排连接器按同针号逐一相连。PWM 则按用户确定的方案，在焊接时反向交叉，使电机板 PWM1..PWM4 对应 TIM1_CH1..CH4；不按主控图纸的 PWM 网名同名直连。

## 主控板核对

| 功能 | 原理图连接 | 核对结果 |
|---|---|---|
| OLED | I2C1：PB6=SCL、PB7=SDA | SSD1306、128×64、7 位地址 0x3C（HAL 地址 0x78）由用户确认 |
| 按键 | 图纸标记 K1=PC0、K2=PC1、K3=PC13 | 2026-11-16 用户指定软件操作名为 KEY1=PC13、KEY2=PC0、KEY3=PC1；按下接 GND，低有效，以该软件编号操作 |
| 蜂鸣器 | PD12 / Buzzer_T1 | 经 R4 4.7 kΩ 驱动 SS8050，MCU 高电平开启蜂鸣器 |
| IMU 控制器 | PB10=SCK、PC2=MISO、PC3=MOSI、PE7=CS、PD0=INT1、PD1=INT2 | 主控侧接口为 H5；INT2 在原理图中有连接 |
| 电机 PWM 网名 | PE14=PWM1、PE13=PWM2、PE11=PWM3、PE9=PWM4 | 主控 5 针接口：1=EN、2=PWM1、3=PWM2、4=PWM3、5=PWM4；焊接时按 TIM1 通道顺序反向交叉，见飞线表 |
| 电机使能 | PD7=EN | 接电机控制口 EN |
| 激光 | PD8 | H4 2 脚为 PD8，1 脚为 GND |
| 模拟量 | PB0=I1/ADC1_IN8；PB1=U1/ADC1_IN9；PC4=U2/ADC1_IN14；PA2=I2/ADC1_IN2 | H6 依次为 1=I2、2=U2、3=U1、4=I1 |
| 其他模拟脚 | PC5 网名 C5 | 没有标注外部功能或传感器去向，暂列未分配 |
| “串口1”接口 | PC6=TX1、PC7=RX1 | STM32F407VET6 的复用功能是 USART6_TX/RX；接口标号“串口1”不是 MCU 外设 USART1 |
| “串口2”接口 | PD5=TX2、PD6=RX2 | 对应 USART2_TX/RX |
| PD10 | 暂不部署 | 原理图未显示它连接到电机板故障输出；不接线、不作为故障反馈使用 |
| PE15 | PE15 | 图纸未显示它连接到电机板保护输入；不能当作已接通的 TIM1 硬件刹车 |

主控“串口1/2”连接器各为 4 针：1 脚 +5V、2 脚 TX、3 脚 RX、4 脚 GND。板间串口线未列入当前 IMU/电机飞线计划。

## 电机板接口核对

| 接口 | 针号 | 原理图信号 |
|---|---:|---|
| H8：ICM-45686 模块 | 1 | VCC |
| H8：ICM-45686 模块 | 2 | INT2 |
| H8：ICM-45686 模块 | 3 | INT1 |
| H8：ICM-45686 模块 | 4 | CS |
| H8：ICM-45686 模块 | 5 | SCL/SCLK |
| H8：ICM-45686 模块 | 6 | SDA/MOSI |
| H8：ICM-45686 模块 | 7 | AD0/MISO |
| H8：ICM-45686 模块 | 8 | GND |
| H2：主控控制输入 | 1 | PWM1 |
| H2：主控控制输入 | 2 | PWM2 |
| H2：主控控制输入 | 3 | PWM3 |
| H2：主控控制输入 | 4 | PWM4 |
| H2：主控控制输入 | 5 | EN |

电机板使用 SN74HC08 将各路 PWM 与 EN 作与门控制；EN 为高时 PWM 才传递到对应驱动输入。H2 没有独立 GND 针，接入控制信号前需确认主控板与电机板逻辑地共地。H7 标为 3.7V/GND，但 MP1584 的 VIN 接 +5V、SW 经电感连电机 3.7V 网；不能仅凭 H7 标注推断所有板级供电。2026-11-16 用户确认实际供电为 5 V，电机端和 SN74HC08 逻辑端电压仍需实测。SN74HC08 在 5 V 下对 MCU 3.3 V 输入没有可靠的高电平裕量保证。

电机板图中还出现 LM393 比较器电路，但 H2 没有故障输出针，原理图也没有画出比较器输出至 PD10 或 PE15 的板间连接。按当前决定，PD10 暂不部署；MCU 故障反馈和硬件刹车均不作为已接通功能。

## 飞线表

### IMU：主控 H5 到电机板 H8

| 信号 | 主控 H5 | 电机板 H8 | MCU 侧 |
|---|---:|---:|---|
| 3.3V | 1（3.3V_A） | 1（VCC） | 供电网名对应 |
| GND | 2（GND） | 8（GND） | 共地 |
| MISO | 3（MISO） | 7（AD0/MISO） | PC2 |
| MOSI | 4（MOSI） | 6（SDA/MOSI） | PC3 |
| SCK | 5（SCK） | 5（SCL/SCLK） | PB10 |
| CS | 6（CS） | 4（CS） | PE7 |
| INT1 | 7（INT1） | 3（INT1） | PD0 |
| INT2 | 8（INT2） | 2（INT2） | PD1 |

### 电机控制：主控 5 针接口到电机板 H2

| 电机板通道 | TIM1 输出 | 主控 5 针接口 | 电机板 H2 |
|---|---|---:|---:|
| EN | PD7 | 1（EN） | 5（EN） |
| PWM1 | PE9 / TIM1_CH1（主控图纸网名 PWM4） | 5（PWM4） | 1（PWM1） |
| PWM2 | PE11 / TIM1_CH2（主控图纸网名 PWM3） | 4（PWM3） | 2（PWM2） |
| PWM3 | PE13 / TIM1_CH3（主控图纸网名 PWM2） | 3（PWM2） | 3（PWM3） |
| PWM4 | PE14 / TIM1_CH4（主控图纸网名 PWM1） | 2（PWM1） | 4（PWM4） |

电机 PWM 接口在主控原理图局部未见清晰的连接器编号，故以“主控 5 针接口”描述。焊接时主控接口 PWM4/PWM3/PWM2/PWM1（脚 5/4/3/2）依次交叉接到 H2 PWM1/PWM2/PWM3/PWM4（脚 1/2/3/4），让 TIM1_CH1..CH4 对应 H2 的 PWM1..PWM4。此方案有意跨接不同网名，不要按 PWM 同名直连。

## 保留项与待同步项

- PA13/PA14 的 SWD、PA11/PA12 的 USB、PC8-PC12/PD2/PD3 的 TF 卡功能按项目规划保留。当前两份图纸没有清楚展示 USB 或 TF 卡座的完整电路，实际装配与占用需以板卡实物/完整设计文件确认。
- PE8、PE10、PE12、PD11、PD13、PD14、PD15、PA4、PA5 继续留作项目预留。
- 当前 `.ioc` 使用 PA9/PA10 作 USART1，但图纸“串口1”接口实际是 PC6/PC7（USART6）。PWM 按本表反向交叉焊接后，PE9/PE11/PE13/PE14 的 TIM1_CH1..CH4 顺序与 H2 PWM1..PWM4 对齐。
- PD10 暂不部署，`.ioc`、GPIO 初始化和引脚宏中的 MOTOR_FAULT 占位已移除；图纸没有故障飞线。
- 2026-11-16：用户确认 PE9 接 PWM1、PD7 接 EN，并准备进行电机1测试。EN 改为开漏/内部上拉，允许板上 LM393/2N7002 将 EN 下拉；不再使用推挽高电平与保护下拉对抗。软件阶段及上板记录见 [电机1测试](../../WindPendulum_F407/电机1测试.md)。
